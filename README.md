# La casita de Beatriz B. Bustamante

Portfolio interactivo de ilustración. Versión normal para ordenador.

- Página principal: `index.html`.
- Acceso directo a los trabajos: `portfolio-editorial.html`.
- Cuento y minijuego: `cuento-interactivo/`.
- Imágenes: `img/`.

Para publicar con GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
Mantén las carpetas y los nombres de los archivos. Los vídeos y algunos audios se cargan desde Cloudinary y necesitan Internet. La escena usa Three.js desde una CDN.

Controles: clic para entrar y descubrir trabajos; WASD o flechas para caminar; Esc para volver.
